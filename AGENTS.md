# AGENTS.md

## Project

Flask website for conceptnull.org. Pulls wiki content from a MediaWiki/SemanticMediaWiki instance and structured data (opportunities, events) from PocketBase.

## Entry points

- `python app.py` — dev server with `debug=True`, creates `WikiApp` directly
- `python application.py` — production/WSGI entry; imports `WikiApp` from `app.py`, exposes `application` for gunicorn

## Data sources

- **MediaWiki API**: `https://wiki.conceptnull.org/api.php` — wiki pages, SMW `ask` queries
- **PocketBase API**: `https://pdb.conceptnull.org` — stored in `.env` as `POCKETBASE_URL` (gitignored) with admin auth credentials

## Environment

`.env` (gitignored) must contain:
- `POCKETBASE_URL`
- `POCKETBASE_ADMIN_EMAIL`
- `POCKETBASE_ADMIN_PASSWORD`

No defaults if missing — PocketBase routes will return empty results.

## Architecture notes

- `WikiApp` subclasses `Flask` and registers all routes in `__init__` — no decorators or blueprints
- `PocketBaseClient` is a standalone class in `pocketbase_client.py` with its own session and auth token caching
- `application.py` exists solely as the gunicorn WSGI callable, importing the class rather than the instance
- MediaWiki HTML is post-processed via `fix_html()` (BeautifulSoup): rewrites image `src`, strips edit-section elements, extracts/wraps tables
- Template partials are prefixed with `_` (e.g., `_nav.html`) and included via Jinja2

## Requirements

Core deps: `Flask`, `requests`, `beautifulsoup4`, `python-dotenv`, `python-dateutil`.

`requirements.txt` is auto-generated by pipreqs with many indirect dependencies pinned. Do not regenerate or prune without testing.

## No tooling

No test runner, linter, formatter, type checker, or CI configured.
